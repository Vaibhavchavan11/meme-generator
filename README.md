# Meme Generator (Full Stack)

A simple **Meme Generator** built with **HTML, CSS, JavaScript, Node.js, and Express**.

## 🚀 Features
- Upload custom images
- Add top & bottom text
- Adjust text position (X & Y sliders)
- Change font size and color
- Download memes as PNG
- Upload memes to server (Node + Express + Multer)
- Responsive, modern UI with gradient background

## 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla JS)
- **Styling**: CSS Flexbox, CSS Grid, Gradient Animations
- **Canvas API**: For rendering images and text
- **Fonts**: Google Fonts (Poppins)
- **Backend**: Node.js, Express.js, Multer, CORS

## ▶️ How to Run
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start backend + frontend together:
   ```bash
   npm start
   ```
3. Open browser:
   ```
   http://127.0.0.1:5000
   ```
